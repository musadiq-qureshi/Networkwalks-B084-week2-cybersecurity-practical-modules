## 📌 About This Project

This repository contains my Week 2 practical work for the **NetworkWalks Cybersecurity Internship – Batch B084**.

The project focuses on learning and practicing fundamental cybersecurity activities, including website footprinting, Open Source Intelligence (OSINT), Google Hacking Database research, and network host discovery.

## 🧪 Practical Modules

### PM1 – Footprinting & Reconnaissance

Explored website information and technology details using:

- WHOIS
- WhatWeb
- Nslookup
- cURL
- WAFW00F
- DNSRecon

**Evidence:** `PM1/`

### PM2 – Google Hacking Database (GHDB)

Explored Google Hacking Database search techniques and reviewed search results for:

- Camera-related search queries
- Mathematical and PDF-related searches
- Google Dorking concepts

**Evidence:** `PM2/`

### PM3 – OSINT with Maltego

Used Maltego to explore domain-related information and email-focused OSINT transforms for the NetworkWalks domain.

**Evidence:** `PM3/`

### PM4 – theHarvester

Explored theHarvester interface and its available functionality to understand its role in gathering publicly available information during OSINT activities.

**Evidence:** `PM4/`

### PM5 – Network Scanning with Zenmap

Used Zenmap in a Kali Linux virtual lab to practice network host discovery and review the detected live hosts.

- Worked in a VirtualBox NAT lab environment.
- Practiced host discovery.
- Observed three live hosts in the virtual lab.

**Evidence:** `PM5/`
